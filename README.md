# 绝对公平的抽奖页

一个无需后台、可自行验证的抽奖网页。页面遵循「先承诺后揭晓」的流程：

1. 生成服务端种子并公布其 SHA-256 哈希作为公开承诺。
2. 收集所有参与者的公开种子。
3. 揭晓服务端种子，基于所有公开输入生成确定性的随机序列并完成抽奖。

任何人都可以复刻整个流程，确认结果未被篡改。

## 使用方式

1. 打开 `index.html`（本地直接双击或用任意静态服务器）。
2. 查看页面顶部的「服务端承诺」哈希。
3. 输入参与者昵称与公开种子，加入奖池。
4. 点击「揭晓并抽奖」，页面会公开服务端种子并生成可复现的中奖顺序。
5. 按日志指引复算 SHA-256 和洗牌步骤，即可验证公平性。

本页面不依赖后端服务，所有数据均在浏览器端完成。
